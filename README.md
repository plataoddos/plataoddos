## Projet

### 💋 [Smash Or Pass](https://github.com/plataoddos/smash-or-pass)

Un bot Discord communautaire pour partager une photo ou une vidéo, la faire vérifier par l’équipe, puis laisser les membres voter. Les publications peuvent être anonymes et les validations sont consignées dans un salon de logs privé.
